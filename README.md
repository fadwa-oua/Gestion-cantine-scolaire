# Gestion de Cantine Scolaire

Site web **Flask** de gestion de cantine scolaire : inscription des élèves, commandes de repas, menus, paiements, stock et rapports nutritionnels, avec un espace administrateur.

## Fonctionnalités
- Inscription et gestion des élèves
- Commandes de repas
- Gestion des menus
- Paiements
- Gestion du stock
- Rapports nutritionnels
- Espace administrateur

## Technologies
- Python / Flask
- SQLite
- HTML / CSS (dossiers `templates/` et `static/`)

## Installation
```bash
git clone https://github.com/fadwa-oua/Gestion-cantine-scolaire.git
cd Gestion-cantine-scolaire
pip install flask
python app.py
```
Puis ouvrir `http://127.0.0.1:5000` dans le navigateur.
